# Калькулятор — лабораторні роботи 1–2

Автор: Котяш Федір.

Історія містить student.html, junior.html, senior.html, гілки арифметичних операцій та злиття у master.

## Збірка
```sh
g++ -std=c++17 -Wall -Wextra calc.cpp -o calc.exe
```

## Запуск
Ввести перше число, номер операції та друге число. Операції: 1 — додавання, 2 — віднімання, 3 — множення, 4 — ділення, 5 — піднесення до степеня. Ділення на нуль та неправильне введення перевіряються.

Приклад: `2 5 5` → `Result = 32`.
